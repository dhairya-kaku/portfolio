# Dhairya Sanghvi — Luxury Editorial Portfolio

## Files
- `index.html` — Home
- `skills.html` — Skills
- `study.html` — Education and learning
- `about.html` — About
- `contact.html` — Contact
- `css/style.css` — Shared design system and responsive styling
- `js/script.js` — Mobile navigation, cinematic reveal effects, loader and contact form behavior

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the **Live Server** extension (or use any local static server).
4. Right-click `index.html` and choose **Open with Live Server**.

## Personalize before publishing
1. Replace the `DS` monogram block with your own photo if you want: put your image in `images/` and edit the portrait placeholder in `index.html` and `about.html`.
2. In `contact.html` and `js/script.js`, replace `your.email@example.com` with your real email.
3. Replace the generic GitHub and LinkedIn links with your profile URLs.
4. Review education wording and add your exact school/college details and certificates.
5. Skill bar widths are illustrative self-assessments. Adjust them to represent your current comfort honestly.

## Notes
- Built with HTML, CSS and vanilla JavaScript; no backend or build step required.
- Google Fonts require an internet connection. The design falls back to system serif/sans-serif fonts.
- The contact form uses `mailto:`. It opens the visitor's email app; it does not send/store messages on a server.
- The page loader and scroll reveal respect `prefers-reduced-motion`.
